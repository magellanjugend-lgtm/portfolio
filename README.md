# 권고운 · 프랜차이즈 교육 경력 웹 포트폴리오

## 실행
압축 해제 후 `index.html`을 브라우저에서 열면 됩니다. 프로젝트 책 표지를 클릭하거나 좌우 화살표로 이동할 수 있습니다. GitHub Pages에 `index.html`과 `content.js`를 함께 올리면 정적 사이트로 공개할 수 있습니다.

## 공개 전 필수 검토
- `content.js`의 이름·이메일 및 역할 설명을 본인이 확인하세요. 회사 인사 자료에는 `매니저/팀원`(2025-12-29), 대화에서 제시된 경력 화면에는 `대리`가 있어 직급을 확정 표기하지 않았습니다.
- 2025년 교육 매장 494개, 만족도 4.92/5는 자기기술서 기준. 인사 자료의 2024년 228개는 부서 운영 기록으로 개인 실적으로 단정하지 않습니다.
- 리더십 과정 240분은 교육안에 표시된 권장 시간으로 실제 진행을 뜻하지 않습니다.
- 고객 VOC 20,849건은 교육자료에 실린 2023년 과거 통계로 개인 실적이 아닙니다.
- 회사 내부 문서 및 교육 PPT 원본은 포함하지 않았습니다. 외부 공개 전 회사 보안 규정과 저작권, 개인정보를 검토하세요.
